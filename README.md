# SpendMe: Akıllı Bütçe Takip Uygulaması

**SpendMe**, kullanıcıların aylık gelir ve giderlerini kolayca takip etmelerini sağlayan, harcamaları otomatik olarak kategorize eden, görsel raporlar sunan ve bütçe yönetimine yardımcı olan modern bir Aşamalı Web Uygulamasıdır (PWA).

## ✨ Temel Özellikler

- **Google ile Güvenli Giriş:** Supabase altyapısı ile hızlı ve güvenli kullanıcı kimlik doğrulama.
- **Kullanıcıya Özel Veri:** Her kullanıcının verisi (hesaplar, işlemler, kategoriler) tamamen kendine özel ve güvenlidir.
- **Hiyerarşik Kategori Yönetimi:** `Gıda > Market` gibi ana ve alt kategoriler oluşturarak harcamalarınızı detaylı bir şekilde sınıflandırın.
- **Otomatik Bakiye Güncelleme:** Veritabanı fonksiyonları sayesinde, her işlemde hesap bakiyeleriniz otomatik ve hatasız olarak güncellenir.
- **Yeni Kullanıcılar İçin Hazır Kategoriler:** Uygulamaya ilk kez giriş yapan kullanıcılar için zengin bir başlangıç kategori seti otomatik olarak oluşturulur.
- **Hesap Yönetimi:** Banka, kredi kartı ve nakit hesaplarınızı tanımlayın ve bakiyelerini anlık olarak takip edin.
- **Bütçe Belirleme ve Takip:** Her kategori için aylık bütçeler oluşturun ve harcama durumunuzu görsel ilerleme çubukları ile izleyin.
- **Modern Mobil Arayüz:** PWA desteği sayesinde telefonunuzun ana ekranına ekleyebilir ve tam bir mobil uygulama deneyimi yaşayabilirsiniz.

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** React (Vite ile), TypeScript, Tailwind CSS
- **Backend & Veritabanı:** Supabase (PostgreSQL, Auth, RLS, DB Functions)
- **Grafikler:** Chart.js
- **Yapay Zeka:** Google Gemini API

## 🚀 Kurulum ve Başlatma

Bu projeyi kendi bilgisayarınızda veya sunucunuzda çalıştırmak için aşağıdaki adımları izleyin.

### 1. Ön Gereksinimler

- Node.js ve npm (veya pnpm/yarn)
- Git
- Bir Supabase hesabı ([ücretsiz](https://supabase.com/))
- Bir Google Cloud hesabı ([ücretsiz deneme](https://cloud.google.com/))

### 2. Supabase Projesi Oluşturma

1.  **Supabase'e gidin** ve yeni bir proje oluşturun.
2.  Sol menüden **Project Settings > API**'ye gidin. **Project URL** ve `anon` `public` anahtarını kopyalayın.

### 3. Google ile Girişi Yapılandırma

1.  **Google Cloud Console**'a gidin ve yeni bir proje oluşturun.
2.  **APIs & Services > OAuth consent screen**'e gidin. "External" seçin ve uygulamanız için bir isim belirleyip gerekli adımları tamamlayın.
3.  **APIs & Services > Credentials**'a gidin. **+ CREATE CREDENTIALS > OAuth client ID**'yi seçin.
    - Application type: **Web application**
    - Authorized redirect URIs: Supabase projenizin **Authentication > Providers > Google** ayarlarında gösterilen **Callback URL**'ini ekleyin. (örn: `https://your-project-id.supabase.co/auth/v1/callback`)
4.  Oluşturulan **Client ID** ve **Client Secret**'ı kopyalayın.
5.  Supabase projenizde **Authentication > Providers > Google**'a gidin, "Enable Sign in with Google" seçeneğini aktif hale getirin ve kopyaladığınız **Client ID** ile **Client Secret**'ı ilgili alanlara yapıştırıp kaydedin.

### 4. Veritabanı Tablolarını ve Fonksiyonlarını Oluşturma

Supabase projenizdeki **SQL Editor**'e gidin, **+ New query**'e tıklayın ve aşağıdaki SQL kodunun tamamını yapıştırıp **RUN** butonuna basın. Bu, uygulamanın ihtiyaç duyduğu tüm tabloları, güvenlik kurallarını ve otomatik bakiye güncelleme mantığını oluşturacaktır.

**Not:** Bu scripti çalıştırmadan önce mevcut `but_` ile başlayan tüm tablolarınızı silmeniz önerilir.

```sql
-- ÖNCEKİ TABLOLARI GÜVENLİ BİR ŞEKİLDE SİLME
DROP TABLE IF EXISTS public.but_transactions;
DROP TABLE IF EXISTS public.but_budgets;
DROP TABLE IF EXISTS public.but_categories;
DROP TABLE IF EXISTS public.but_accounts;

-- 1. HESAPLAR TABLOSU
CREATE TABLE public.but_accounts (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
    name text NOT NULL,
    type text NOT NULL CHECK (type IN ('bank', 'credit_card', 'cash')),
    balance numeric NOT NULL DEFAULT 0,
    card_number text,
    expiry_date text,
    statement_date integer,
    payment_due_date integer,
    created_at timestamptz DEFAULT now()
);

-- 2. KATEGORİLER TABLOSU (HİYERARŞİK YAPI)
CREATE TABLE public.but_categories (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
    name text NOT NULL,
    type text NOT NULL CHECK (type IN ('income', 'expense')),
    parent_id bigint REFERENCES public.but_categories(id) ON DELETE CASCADE,
    created_at timestamptz DEFAULT now(),
    UNIQUE(user_id, name, parent_id)
);

-- 3. İŞLEMLER TABLOSU
CREATE TABLE public.but_transactions (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
    description text NOT NULL,
    amount numeric NOT NULL,
    date date NOT NULL,
    type text NOT NULL CHECK (type IN ('income', 'expense', 'transfer')),
    category_id bigint REFERENCES public.but_categories(id) ON DELETE SET NULL,
    account_id bigint REFERENCES public.but_accounts(id) ON DELETE SET NULL,
    from_account_id bigint REFERENCES public.but_accounts(id) ON DELETE SET NULL,
    to_account_id bigint REFERENCES public.but_accounts(id) ON DELETE SET NULL,
    ai_prompt text,
    created_at timestamptz DEFAULT now()
);

-- 4. BÜTÇELER TABLOSU
CREATE TABLE public.but_budgets (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
    category_id bigint NOT NULL UNIQUE REFERENCES public.but_categories(id) ON DELETE CASCADE,
    "limit" numeric NOT NULL,
    created_at timestamptz DEFAULT now()
);

-- GÜVENLİK (ROW LEVEL SECURITY) POLİTİKALARI
ALTER TABLE public.but_accounts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage their own accounts." ON public.but_accounts FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
ALTER TABLE public.but_categories ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage their own categories." ON public.but_categories FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
ALTER TABLE public.but_transactions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage their own transactions." ON public.but_transactions FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
ALTER TABLE public.but_budgets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage their own budgets." ON public.but_budgets FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);

-- HESAP BAKİYESİNİ GÜNCELLEMEK İÇİN VERİTABANI FONKSİYONU VE TRIGGER'I
CREATE OR REPLACE FUNCTION public.handle_transaction_change()
RETURNS TRIGGER AS $$
BEGIN
    -- For INSERT
    IF TG_OP = 'INSERT' THEN
        IF NEW.type = 'income' THEN
            UPDATE public.but_accounts SET balance = balance + NEW.amount WHERE id = NEW.account_id;
        ELSIF NEW.type = 'expense' THEN
            UPDATE public.but_accounts SET balance = balance - NEW.amount WHERE id = NEW.account_id;
        ELSIF NEW.type = 'transfer' THEN
            UPDATE public.but_accounts SET balance = balance - NEW.amount WHERE id = NEW.from_account_id;
            UPDATE public.but_accounts SET balance = balance + NEW.amount WHERE id = NEW.to_account_id;
        END IF;
    -- For DELETE
    ELSIF TG_OP = 'DELETE' THEN
        IF OLD.type = 'income' THEN
            UPDATE public.but_accounts SET balance = balance - OLD.amount WHERE id = OLD.account_id;
        ELSIF OLD.type = 'expense' THEN
            UPDATE public.but_accounts SET balance = balance + OLD.amount WHERE id = OLD.account_id;
        ELSIF OLD.type = 'transfer' THEN
            UPDATE public.but_accounts SET balance = balance + OLD.amount WHERE id = OLD.from_account_id;
            UPDATE public.but_accounts SET balance = balance - OLD.amount WHERE id = OLD.to_account_id;
        END IF;
    END IF;
    RETURN NULL;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

-- TRIGGER'I OLUŞTURMA
CREATE TRIGGER on_transaction_change
AFTER INSERT OR DELETE ON public.but_transactions
FOR EACH ROW EXECUTE FUNCTION public.handle_transaction_change();


-- YENİ KULLANICILAR İÇİN BAŞLANGIÇ KATEGORİLERİ OLUŞTURMA FONKSİYONU
CREATE OR REPLACE FUNCTION public.add_initial_categories()
RETURNS void AS $$
DECLARE
    -- Değişkenleri burada tanımla
    gida_market_id bigint;
    faturalar_id bigint;
    ulasim_id bigint;
    kisisel_id bigint;
    ev_yasam_id bigint;
    eglence_id bigint;
    user_has_categories boolean;
BEGIN
    -- Kullanıcının zaten kategorisi olup olmadığını kontrol et
    SELECT EXISTS (SELECT 1 FROM public.but_categories WHERE user_id = auth.uid()) INTO user_has_categories;

    -- Eğer kategorisi yoksa, başlangıç kategorilerini ekle
    IF NOT user_has_categories THEN
        -- Ana Gelir Kategorileri
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Maaş', 'income');
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Ek Gelir', 'income');

        -- Ana Gider Kategorileri
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Gıda & Market', 'expense') RETURNING id INTO gida_market_id;
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Faturalar', 'expense') RETURNING id INTO faturalar_id;
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Ulaşım', 'expense') RETURNING id INTO ulasim_id;
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Kişisel Harcamalar', 'expense') RETURNING id INTO kisisel_id;
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Ev & Yaşam', 'expense') RETURNING id INTO ev_yasam_id;
        INSERT INTO public.but_categories (user_id, name, type) VALUES (auth.uid(), 'Eğlence', 'expense') RETURNING id INTO eglence_id;

        -- Alt Kategoriler
        INSERT INTO public.but_categories (user_id, name, type, parent_id) VALUES
        (auth.uid(), 'Süpermarket', 'expense', gida_market_id),
        (auth.uid(), 'Restoran & Kafe', 'expense', gida_market_id),
        (auth.uid(), 'Dışarıdan Sipariş', 'expense', gida_market_id),
        (auth.uid(), 'Elektrik', 'expense', faturalar_id),
        (auth.uid(), 'Su', 'expense', faturalar_id),
        (auth.uid(), 'İnternet & Telefon', 'expense', faturalar_id),
        (auth.uid(), 'Yakıt', 'expense', ulasim_id),
        (auth.uid(), 'Toplu Taşıma', 'expense', ulasim_id),
        (auth.uid(), 'Giyim & Aksesuar', 'expense', kisisel_id),
        (auth.uid(), 'Sağlık & Eczane', 'expense', kisisel_id),
        (auth.uid(), 'Kira', 'expense', ev_yasam_id),
        (auth.uid(), 'Aidat', 'expense', ev_yasam_id),
        (auth.uid(), 'Sinema & Tiyatro', 'expense', eglence_id),
        (auth.uid(), 'Hobi', 'expense', eglence_id);
    END IF;
END;
$$ LANGUAGE plpgsql;
```

### 5. Projeyi Klonlayın ve Bağımlılıkları Kurun

```bash
git clone https://github.com/fikrierenn/butce.git
cd butce
npm install --legacy-peer-deps
```

**Not:** `--legacy-peer-deps` bayrağı, React 19 ile bazı paketler arasındaki peer dependency uyarılarını atlamak için gereklidir.

### 6. API Anahtarlarını Yapılandırın

#### Supabase Yapılandırması
`lib/supabaseClient.ts` dosyasını açın ve kendi Supabase bilgilerinizi girin:

```typescript
const supabaseUrl = 'https://YOUR-PROJECT-ID.supabase.co';
const supabaseAnonKey = 'YOUR-ANON-KEY';
```

#### Gemini API Yapılandırması
`lib/gemini.ts` dosyasını açın ve Google Gemini API anahtarınızı girin:

```typescript
const genAI = new GoogleGenerativeAI("YOUR-GEMINI-API-KEY");
```

**Güvenlik Notu:** Üretim ortamında API anahtarlarını kod içinde saklamayın. Ortam değişkenleri (`.env`) kullanın ve `.gitignore`'a ekleyin.

### 7. Uygulamayı Başlatın

```bash
npm run dev
```

Uygulama `http://localhost:3000` adresinde çalışacaktır. Tarayıcınızda bu adresi açarak uygulamayı kullanmaya başlayabilirsiniz.

### 8. Build (Üretim İçin Derleme)

```bash
npm run build
```

Derlenmiş dosyalar `dist` klasöründe oluşturulur ve herhangi bir statik hosting servisine (Vercel, Netlify, GitHub Pages vb.) deploy edilebilir.
